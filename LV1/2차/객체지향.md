# 객체지향 프로그래밍(OOP)

## 1. 객체지향이란?
객체지향(Object-Oriented Programming)은 데이터와 기능을 하나로 묶어 객체 단위로 프로그램을 구성하는 프로그래밍 방식이다.

---

## 2. 객체(Object)와 클래스(Class)

### 객체(Object)
- 실제로 생성된 인스턴스
- 예: Dog d1 = new Dog();

### 클래스(Class)
- 객체를 만들기 위한 설계도

---

## 3. 객체지향의 4대 특징

### 1) 캡슐화 (Encapsulation)
- 데이터와 메서드를 하나로 묶음
- 외부 접근을 제한하여 데이터 보호

### 2) 상속 (Inheritance)
- 기존 클래스를 재사용하여 새로운 클래스 생성

### 3) 다형성 (Polymorphism)
- 하나의 타입으로 여러 객체를 다룰 수 있음

### 4) 추상화 (Abstraction)
- 공통된 특징을 추출하여 표현
- 불필요한 정보는 숨김

---

## 4. 장점

- 코드 재사용성 증가
- 유지보수 용이
- 확장성 증가
- 구조적인 설계 가능
