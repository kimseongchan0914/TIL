# 2일차 정리  컬렉션 프레임워크

---

## 컬렉션 3형제 요약
| | 순서 | 중복 | 접근 방법 | 언제 쓸까 |
|---|---|---|---|---|
| **List** | 있음 | 허용 | 인덱스 (0, 1, 2...) | 순서 중요, 중복 OK (게시글 목록, 장바구니) |
| **Set** | 없음* | 불가 | 값 존재 여부 확인 | 중복 제거 (방문 ID, 태그) |
| **Map** | 없음* | 키 불가 | 키로 값 조회 | 이름표로 데이터 찾기 (회원ID → 회원정보) |

(*순서가 필요하면 `Linked~` / `Tree~` 변형 사용)

---

## List — 순서 있고 중복 허용
```java
List<String> list = new ArrayList<>();
list.add("kim");
list.add("lee");
list.add("kim");   // 중복 OK
// [kim, lee, kim]
```
- 순서 유지 (넣은 순서대로)
- 중복 허용
- 인덱스로 접근: `list.get(0)`

## Set — 중복 없음
```java
Set<String> set = new HashSet<>();
set.add("kim");
set.add("lee");
set.add("kim");   // 무시됨 (이미 존재)
// [kim, lee]
```
- 중복 불가
- HashSet은 순서 보장 안 됨
- 중복 제거가 필요할 때 사용

## Map — 키-값 쌍
```java
Map<String, Integer> map = new HashMap<>();
map.put("kim", 25);
map.put("lee", 30);
// {kim=25, lee=30}
```
- 키로 값을 빠르게 조회
- 키는 중복 불가, 값은 중복 가능

---

## 구현체 선택 가이드
| 계열 | 기본 (제일 많이 씀) | 순서 유지 | 자동 정렬 |
|---|---|---|---|
| List | `ArrayList` | (기본이 순서 유지) | — |
| Set | `HashSet` | `LinkedHashSet` | `TreeSet` |
| Map | `HashMap` | `LinkedHashMap` | `TreeMap` |

> 실무 습관: 기본은 `ArrayList` / `HashSet` / `HashMap`.
> "순서가 필요하네?" → `Linked~`, "정렬이 필요하네?" → `Tree~`

---

## 순회(반복)하는 법
```java
// List 순회
for (String name : list) {
    System.out.println(name);
}

// Map 순회 (키-값 함께)
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    System.out.println(entry.getKey() + " = " + entry.getValue());
}
```
