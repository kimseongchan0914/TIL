# 📚 백엔드 개인 과제

> 백엔드 개발을 학습하며 진행한 개인 과제와 학습 내용을 정리한 저장소입니다.

---

## 📖 소개

이 저장소는 백엔드 개발을 공부하면서 학습한 내용을 직접 정리하고, 개인 과제를 수행하며 배운 내용을 기록하기 위해 만든 저장소입니다.

단순히 과제를 제출하는 것이 아니라, 개념을 이해하고 다시 찾아볼 수 있도록 이론과 예제 코드를 함께 정리하는 것을 목표로 합니다.
