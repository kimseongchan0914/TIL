# Java & Spring Annotation 정리

## 1. Annotation(어노테이션)이란?

어노테이션(Annotation)은 코드에 **메타데이터(부가 정보)**를 추가하는 문법이다.  
Spring과 같은 프레임워크가 이를 읽어서 특정 동작을 수행한다.

- 코드 실행 로직을 직접 바꾸는 것이 아니라 **설정과 역할을 지정**
- 컴파일러 또는 프레임워크가 해석하여 동작

---

## 2. Java 기본 어노테이션

### @Override
부모 클래스의 메서드를 재정의했음을 명시

- 오타나 잘못된 오버라이딩 방지
- 컴파일 단계에서 오류 체크

```java
@Override
public String toString() {
    return "Hello";
}
```

---

### @Deprecated
더 이상 사용을 권장하지 않는 코드 표시

- 사용 시 경고 발생

```java
@Deprecated
public void oldMethod() {}
```

---

### @SuppressWarnings
컴파일 경고를 무시

- 주로 제네릭 관련 경고 제거

```java
@SuppressWarnings("unchecked")
```

---

## 3. Spring 핵심 어노테이션

### @Component
Spring이 해당 클래스를 Bean으로 등록

- 객체를 자동 생성 및 관리

```java
@Component
public class MyClass {}
```

---

### @Controller
웹 요청을 처리하는 클래스

- URL 요청을 받아 처리

```java
@Controller
public class MyController {}
```

---

### @RestController
Controller + ResponseBody

- 반환값을 JSON 형태로 응답

```java
@RestController
public class ApiController {}
```

---

### @Service
비즈니스 로직 담당

- 데이터 처리, 계산 등 핵심 기능 수행

```java
@Service
public class MyService {}
```

---

### @Repository
DB 접근 담당

- 예외를 Spring이 자동 처리

```java
@Repository
public class MyRepository {}
```

---

## 4. 의존성 주입 (DI)

### @Autowired
Spring이 객체를 자동으로 주입

```java
@Autowired
private MyService myService;
```

---

### @RequiredArgsConstructor (Lombok)
final 필드를 생성자로 자동 주입

- 코드 간결화

```java
@RequiredArgsConstructor
public class MyService {
    private final MyRepository repo;
}
```

---

## 5. 요청 처리 어노테이션

### @RequestMapping
모든 HTTP 요청 매핑

```java
@RequestMapping("/home")
```

---

### @GetMapping
GET 요청 처리 (조회)

```java
@GetMapping("/list")
```

---

### @PostMapping
POST 요청 처리 (데이터 저장)

```java
@PostMapping("/save")
```

---

### @PathVariable
URL 경로 변수 추출

```java
@GetMapping("/user/{id}")
public String getUser(@PathVariable int id) {}
```

---

### @RequestParam
쿼리 파라미터 값 추출

```java
@GetMapping("/search")
public String search(@RequestParam String keyword) {}
```

---

## 6. 응답 처리

### @ResponseBody
데이터를 그대로 HTTP 응답으로 반환

```java
@ResponseBody
public String hello() {
    return "hello";
}
```

---

## 7. 트랜잭션

### @Transactional
DB 작업을 하나의 단위로 처리

- 실패 시 롤백

```java
@Transactional
public void save() {}
```

---

## 8. Lombok 어노테이션

### @Getter / @Setter
getter, setter 자동 생성

```java
@Getter
@Setter
private String name;
```

---

### @NoArgsConstructor
기본 생성자 생성

```java
@NoArgsConstructor
```

---

### @AllArgsConstructor
모든 필드 생성자 생성

```java
@AllArgsConstructor
```

---

## 9. JPA 어노테이션

### @Entity
DB 테이블과 매핑되는 클래스

```java
@Entity
public class User {}
```

---

### @Id
기본 키 지정

```java
@Id
private Long id;
```

---

### @GeneratedValue
자동 증가 값 설정

```java
@GeneratedValue
private Long id;
```

---

### @Column
컬럼 설정

```java
@Column(name = "user_name")
private String name;
```

---

## 10. 전체 흐름 정리

```
Controller → Service → Repository → DB
```

- Controller: 요청 처리
- Service: 비즈니스 로직
- Repository: DB 접근
- Entity: DB 테이블 구조

---

## 핵심 요약

- 어노테이션 = 설정 + 역할 지정 도구
- Spring은 어노테이션 기반 프레임워크
- 코드보다 "구조"를 이해하는 것이 중요
