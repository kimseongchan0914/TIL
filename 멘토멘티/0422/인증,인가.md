# 인증 / 인가 한 번에 정리

## 차이점

* 인증 → 너 누구야?
* 인가 → 이거 해도 돼?

이렇게 생각하면 끝입니다.

---

## 인증 (Authentication)

사용자가 진짜 맞는지 확인하는 과정

예: 로그인

```java id="7m2xv1"
if (user.getPassword().equals(inputPassword)) {
    // 로그인 성공
}
```

---

## 인가 (Authorization)

로그인한 사용자가 어떤 기능까지 가능한지 확인

예: 관리자만 삭제 가능

```java id="n4z9ka"
if (user.getRole().equals("ADMIN")) {
    // 삭제 가능
}
```

---

## 흐름

1. 로그인 한다 (인증)
2. 요청 보낸다
3. 권한 확인한다 (인가)
4. 되면 실행
